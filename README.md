# 🧑‍🍳 Chef In You

**Chef In You** is a web application for creating, editing, and viewing recipes. Users can:

- 💬 Register and log in via Google.
- ✍️ Create, edit, and delete recipes.
- 📝 View and write articles.
- 📸 Upload dish photos.

## ⚙️ Technologies

- **React**: for building the user interface.
- **TypeScript**: for static typing and safer code.
- **SCSS**: for styling with variables and mixins.
- **Vercel**: for hosting and CI/CD.
- **JavaScript**: for interactivity and logic.

## 🚀 Features

- 🔐 Google authentication.
- 🧩 Modal windows for adding and editing recipes.
- 📱 Responsive design for mobile devices.
- 🗂️ Organized recipe cards with images and descriptions.
- 🔍 Search functionality to quickly find recipes.
- 🗒️ Ability to categorize and filter recipes.
